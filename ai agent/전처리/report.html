Model Comparison

단계별 모델 성능 비교

모델 변수 수 AUC-ROC F1 Precision Recall
Baseline 구독 정보만 12개 0.5690 0.6491 0.7571 0.5681
전처리 완료 전체 파생변수 93개 (전체 100개 중 ID·타겟 7개 제외) 0.8845 0.8557 0.8978 0.8174
다중공선성 제거 ★ 채택 74개 0.8826 0.8582 0.9015 0.8189
SHAP 기반 추가 제거 61개 0.8837 0.8538 0.9012 0.8111

✅ 최종 모델 채택 이유

다중공선성 제거 모델이 F1(0.8582)과 Recall(0.8189) 모두 최고.

이탈 예측에서 Recall이 중요한 이유: 실제 이탈자를 놓치면 비용이 크기 때문. 변수 74개로 해석 가능한 범위이며, VIF 제거가 노이즈를 줄여 오히려 성능 향상.

🔑 핵심 발견

Baseline AUC 0.5690 → 전처리 후 0.8826
차이: +0.3136 — 시청 이력 파생변수가 예측력의 핵심.

구독 정보(나이, 요금제)만으로는 이탈 예측이 불가능하며, 시청 행동 데이터가 절대적으로 필요함을 증명.

🌳 Surrogate Tree 핵심 규칙

【이탈 규칙】 IF dur_w3 ≤ 3.5분 ← 3주차 거의 안 봄 AND dur_w2 ≤ 62.5분 ← 2주차도 적음 AND week1_ratio ≤ 0.355 ← 1주차 집중도 낮음 AND price_per_day ≤ 13.89원 ← 저가 요금제 → 이탈 확률 높음 【재구매 규칙】 IF dur_w3 > 3.5분 ← 3주차에도 시청 지속 AND action_sf_thriller ≤ 0.5 ← 장르 편향 낮음 AND horror_ratio ≤ 0.233 ← 공포 집중 아님 → 재구매 확률 높음

Conclusion

결론 및 기여

📌 핵심 결론

  1. 시청 이력 파생변수가 이탈 예측의 핵심 (AUC +0.31)
  2. 3주차 시청이 재구매 여부를 결정하는 단일 최강 예측 변수
  3. 드라마·패밀리·로맨스 시청자 = 재구매, 스릴러·공포 집중 = 이탈
  4. 다중공선성 제거가 변수를 줄이면서 성능을 유지 (F1 +0.003)
  5. AI 기반 개인화 개입으로 이탈 방지 액션 자동화 가능
