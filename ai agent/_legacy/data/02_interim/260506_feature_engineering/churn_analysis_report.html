LIME vs SHAP 차이
  • SHAP: 전체 모델 관점에서 변수 중요도 → "어떤 변수가 전반적으로 중요한가"
  • LIME: 개별 고객 1명의 예측 근거 → "이 고객이 왜 이탈로 예측됐는가"
