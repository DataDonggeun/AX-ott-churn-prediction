특성공학(Feature Engineering)이란?

데이터를 모델에 넣기 전에 어떻게 표현하느냐가 모델 성능에 결정적인 영향을 미친다. 같은 데이터라도 표현 방법에 따라 선형 모델이 비선형 패턴을 학습할 수 있고, 반대로 복잡한 모델이 더 단순해질 수도 있다.

원-핫 인코딩

범주형 변수를 숫자로 변환. "서울/부산/대구" → 세 개의 0/1 컬럼

구간 분할

연속 값을 구간으로 나눔. 나이 → 10대/20대/30대...

상호작용/다항식

피처 간 조합으로 새 피처 생성. A × B, A²

핵심

모델이 좋아지려면 데이터를 더 많이 모으거나, 더 복잡한 모델을 쓰거나, 더 좋은 피처를 만들어야 한다. 특성공학은 세 번째 방법이다.

pp. 288 – 301

범주형 변수 — 원-핫 인코딩

머신러닝 모델은 숫자만 다룰 수 있다. 문자열로 된 범주형 변수(예: 성별, 직업, 지역)를 숫자로 변환해야 한다.

왜 단순 숫자 매핑은 안 되나?

"서울=1, 부산=2, 대구=3"으로 매핑하면 모델이 "대구 > 부산 > 서울"처럼 순서가 있다고 잘못 학습한다. 범주형에는 순서가 없는데 수치 관계가 생겨버리는 것이다.

원-핫 인코딩 (One-Hot Encoding)

각 범주를 별도의 0/1 이진 컬럼으로 만드는 방법. 범주 간 순서 관계가 없어서 모델이 올바르게 학습한다.

원-핫 인코딩 — 범주마다 0/1 컬럼이 생기고, 해당 범주면 1 나머지는 0
from sklearn.preprocessing import OneHotEncoder
import pandas as pd

# pandas get_dummies 방법
df_dummies = pd.get_dummies(df, columns=['city', 'gender'])

# sklearn OneHotEncoder 방법 (Pipeline에서 사용)
ohe = OneHotEncoder(sparse_output=False, handle_unknown='ignore')
X_encoded = ohe.fit_transform(X[['city']])
주의 — handle_unknown='ignore'

학습 데이터에 없던 새로운 범주가 테스트 데이터에 나타날 수 있다. handle_unknown='ignore'로 설정하면 모르는 범주를 모두 0으로 처리해서 오류를 방지한다.

순서가 있는 범주형 — OrdinalEncoder

"낮음/보통/높음"처럼 순서가 있는 범주는 OrdinalEncoder를 써서 0, 1, 2로 매핑한다. 원-핫보다 컬럼 수가 늘어나지 않아서 효율적이다.

from sklearn.preprocessing import OrdinalEncoder

oe = OrdinalEncoder(categories=[['낮음', '보통', '높음']])
X_ord = oe.fit_transform(X[['등급']])

구간 분할 (Binning / Discretization)

연속적인 숫자 특성을 구간으로 나누는 방법이다. 나이(27.5세)를 "20대"로 바꾸는 것이 대표적인 예시다.

왜 구간 분할을 하나?

선형 모델에 도움이 됨

선형 모델은 직선만 그릴 수 있다. 연속값을 구간으로 나누면 각 구간에 별도의 계수를 학습할 수 있어서 비선형 패턴을 학습 가능해진다.

트리 모델에는 불필요

트리 기반 모델(랜덤 포레스트, 그래디언트 부스팅)은 이미 스스로 구간을 찾는다. 미리 구간을 나눠도 효과가 없거나 오히려 정보 손실이 생긴다.

from sklearn.preprocessing import KBinsDiscretizer

# 10개 구간으로 나누기, 원-핫 인코딩 방식
kb = KBinsDiscretizer(n_bins=10, strategy='uniform', encode='onehot-dense')
X_binned = kb.fit_transform(X)

# strategy 옵션:
# 'uniform'  → 동일한 너비의 구간
# 'quantile' → 동일한 샘플 수의 구간 (기본값)
# 'kmeans'   → k-평균으로 구간 결정
구간 분할이 효과적인 상황
  • 연속 특성과 타겟 사이에 비선형 관계가 있을 때
  • 선형 모델, 나이브 베이즈 등 단순한 모델을 쓸 때
  • 특정 범위에서만 특별한 패턴이 있을 때

구간 분할 + 상호작용 = 강력한 조합

구간으로 나눈 피처 두 개를 곱하면(상호작용) 선형 모델도 2차원 비선형 패턴을 학습할 수 있다.

# 구간 분할 후 상호작용
X_binned = kb.fit_transform(X)
X_product = X_binned[:, 0:1] * X_binned[:, 1:2]   # 두 피처의 조합

ColumnTransformer — 피처마다 다른 전처리

실제 데이터는 수치형 컬럼과 범주형 컬럼이 섞여 있다. 각 컬럼에 서로 다른 전처리를 적용해야 할 때 ColumnTransformer를 사용한다.

ColumnTransformer — 컬럼별로 다른 변환기를 적용하고 결과를 합침
from sklearn.compose import ColumnTransformer, make_column_transformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder, KBinsDiscretizer

# 방법 1: ColumnTransformer 직접 사용
ct = ColumnTransformer([
    ("scale",  StandardScaler(),             ['age', 'income']),
    ("onehot", OneHotEncoder(sparse_output=False), ['gender', 'city']),
])

# 방법 2: make_column_transformer (이름 자동 지정, 더 간결)
ct = make_column_transformer(
    (StandardScaler(),                          ['age', 'income']),
    (OneHotEncoder(sparse_output=False),        ['gender', 'city']),
)

X_trans = ct.fit_transform(X_train)   # 학습+변환
X_test_trans = ct.transform(X_test)  # 테스트는 transform만!
Pipeline과 함께 쓰기 (실전 패턴)
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression

pipe = Pipeline([
    ("preprocess", ct),
    ("model",      LogisticRegression()),
])
pipe.fit(X_train, y_train)
pipe.score(X_test, y_test)
remainder 매개변수

지정하지 않은 컬럼은 기본적으로 버려진다. 남기고 싶으면 remainder='passthrough'로 설정하면 된다.

상호작용과 다항식 특성

두 피처를 곱하거나 제곱하는 방식으로 새로운 피처를 만들어 모델의 표현력을 높인다.

상호작용 특성 (Interaction Features)

두 피처 A와 B를 곱한 A×B는 "A와 B의 동시 영향"을 캡처한다. 예를 들어 나이와 소득을 곱하면 "나이와 소득이 모두 높은 경우"를 따로 학습할 수 있다.

언제 유용한가?
  • 두 피처가 함께 작용할 때
  • 선형 모델에서 비선형 관계를 표현할 때
  • 구간 분할된 피처들의 조합으로
단점
  • 피처 수가 폭발적으로 증가
  • n개 피처 → n(n+1)/2개 상호작용
  • 해석이 어려워짐

다항식 특성 (Polynomial Features)

원래 피처의 제곱, 세제곱 등을 추가한다. 예를 들어 x → x, x², x³. 이렇게 하면 선형 모델이 곡선을 학습할 수 있다.

from sklearn.preprocessing import PolynomialFeatures

# degree=2: x1, x2 → x1, x2, x1², x1·x2, x2²
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X)

print("원본 피처 수:", X.shape[1])
print("다항식 피처 수:", X_poly.shape[1])
구간 분할 + 상호작용 조합의 효과

구간 분할로 각 구간을 0/1로 만들고, 이를 서로 곱(상호작용)하면 "x가 특정 구간이면서 y도 특정 구간"이라는 복잡한 조건을 선형 모델도 학습할 수 있다. 결정 트리처럼 동작하는 효과.

커널 SVM과의 비교

다항식 특성을 직접 만들지 않고도 커널 SVM을 사용하면 비슷한 복잡도의 예측을 만들 수 있다. 커널 SVM은 내부적으로 고차원 변환을 수행하므로 특성을 직접 만들 필요가 없지만, 해석이 어렵고 데이터가 많으면 느려지는 단점이 있다.

다항식 특성 + 선형 모델
  • 특성을 직접 만들어 넣음
  • 해석 가능 (어떤 특성이 중요한지 확인)
  • 피처 수 폭발 주의
커널 SVM
  • 변환을 내부적으로 처리 (커널 트릭)
  • 해석 어려움
  • 대용량 데이터에 느림

수학 함수 변환 — log / exp / sin

제곱·세제곱 외에도 log, exp, sin 같은 수학 함수를 특성에 적용하면 모델 성능이 크게 올라가는 경우가 있다. 특히 선형 모델과 신경망은 각 특성의 스케일과 분포에 민감하기 때문이다.

언제 쓰나? — 카운트 데이터

사용자 로그인 횟수, 시청 횟수처럼 정수이고 음수가 없는 카운트 데이터는 오른쪽으로 치우친 분포를 가진다. 이런 데이터에 Ridge 같은 선형 모델을 그냥 쓰면 성능이 낮게 나온다.

변환 전 — 선형 모델 실패

카운트 데이터를 그대로 Ridge 회귀에 넣으면 결정계수(R²)가 매우 낮게 나온다. 스케일이 크게 치우쳐 있어서 모델이 관계를 제대로 학습 못 함.

변환 후 — log 스케일

log 변환 후 같은 모델을 쓰면 R²가 크게 올라간다. 분포가 정규분포에 가까워져서 선형 모델이 관계를 잘 학습할 수 있게 됨.

import numpy as np

# 0이 있으면 log(X+1) 사용 (log(0)은 정의 안 됨)
X_log = np.log(X + 1)

# exp 변환 (log의 역변환, 로그 스케일 → 원래 스케일)
X_exp = np.exp(X)

# 주기성 있는 특성 (시간, 요일 등)
X_sin = np.sin(2 * np.pi * X / 24)   # 24시간 주기
대부분의 모델은 정규분포에 가까울 때 최고 성능

히스토그램이 종 모양(정규분포)에 가까울수록 선형 모델과 신경망이 잘 작동한다. log/exp 변환은 치우친 분포를 종 모양에 가깝게 만드는 편리한 방법이다.

트리 모델은 변환 불필요

트리 기반 모델(랜덤 포레스트, XGBoost 등)은 특성의 순서에만 영향받기 때문에 log 변환을 해도 결과가 같다. 변환이 필요한 건 주로 선형 모델, SVM, 신경망이다.

외삽(Extrapolation) 주의 — 트리 모델의 한계

랜덤 포레스트 같은 트리 모델은 훈련 데이터 범위 밖의 값을 예측하지 못한다. 범위 밖에서는 마지막으로 본 값을 그대로 반복(수평선)하기 때문에 시계열 데이터에 트리 모델을 쓸 때 반드시 주의해야 한다.

  • 선형 모델: 직선을 연장 → 외삽 가능
  • 트리 모델: 마지막 값 반복 → 외삽 불가

특성 자동 선택 — 일변량 통계

모든 피처가 유용한 게 아니다. 불필요한 피처를 제거하면 모델이 더 단순해지고 과적합이 줄어든다. 특성 선택 방법 중 가장 기본은 일변량 통계다.

동작 원리

각 피처와 타겟 사이의 통계적 관계(분산 분석, 카이제곱 등)를 계산해서 관계가 없는 피처를 버린다. 각 피처를 독립적으로 평가한다는 점이 특징이다.

from sklearn.feature_selection import SelectPercentile, SelectKBest, f_classif

# 상위 50% 피처만 선택
select = SelectPercentile(score_func=f_classif, percentile=50)
X_selected = select.fit_transform(X_train, y_train)

# 상위 k개 피처만 선택
select_k = SelectKBest(score_func=f_classif, k=10)
X_k = select_k.fit_transform(X_train, y_train)

# 어떤 피처가 선택됐는지 확인
print(select.get_support())   # True/False 배열
장점
  • 계산이 매우 빠름
  • 피처가 매우 많을 때 유용
  • 모델에 독립적으로 사용 가능
단점
  • 피처 간 상호작용을 고려 안 함
  • 단독으로는 약하지만 조합으로 강한 피처를 버릴 수 있음
6
pp. 318 – 322

모델 기반 특성 선택

지도 학습 모델을 사용해서 피처의 중요도를 계산하고, 중요하지 않은 피처를 제거하는 방법이다. 일변량 통계와 달리 피처 간 관계를 고려한다.

어떤 모델을 쓰나?

선형 모델

계수(coef_)의 절댓값이 작은 피처를 제거. L1 규제(Lasso)를 쓰면 불필요한 피처의 계수가 0이 된다.

트리 기반 모델

feature_importances_로 피처 중요도 계산. 랜덤 포레스트, 그래디언트 부스팅이 대표적.

SelectFromModel

sklearn의 래퍼. 어떤 모델이든 특성 선택기로 바꿔준다.

from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier

# 랜덤 포레스트 기반 특성 선택
select = SelectFromModel(
    RandomForestClassifier(n_estimators=100, random_state=42),
    threshold="median"    # 중앙값보다 중요한 피처만
)
select.fit(X_train, y_train)
X_selected = select.transform(X_train)

print("원본 피처 수:", X_train.shape[1])
print("선택된 피처 수:", X_selected.shape[1])
주의 — 특성 선택에 쓰는 모델 ≠ 최종 모델

특성 선택을 위해 랜덤 포레스트를 쓰고, 실제 예측은 로지스틱 회귀로 할 수 있다. 특성 선택용 모델은 중요도를 계산하는 도구일 뿐이다.

반복적 특성 선택 — RFE

RFE (Recursive Feature Elimination)는 피처를 하나씩 제거해가면서 최적의 피처 집합을 찾는 방법이다. 가장 덜 중요한 피처를 반복적으로 제거한다.

1
전체 피처로 모델 학습모든 피처를 사용해서 모델을 학습하고 각 피처의 중요도를 계산한다.
2
가장 중요도 낮은 피처 제거중요도가 가장 낮은 피처를 하나 제거한다.
3
반복원하는 피처 수가 남을 때까지 1~2를 반복한다.
from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression

# 최종 피처 40개 선택
rfe = RFE(estimator=LogisticRegression(), n_features_to_select=40)
rfe.fit(X_train, y_train)
X_rfe = rfe.transform(X_train)

전문가 지식 활용 — 시계열 예제

책에서는 시티바이크 자전거 대여 데이터로 예제를 진행했는데, 스팀 게임 데이터로 더 쉽게 이해해보자.

문제 상황

스팀에서 게임 평점이나 구매 여부를 예측한다고 할 때, 원본 데이터에는 숫자만 있다.

원본 데이터 (숫자만 있음)

용량: 45000 (MB)  |  출시일: 20231105  |  가격: 29900  |  장르코드: 3

→ 이 숫자만으로는 모델이 "AAA 대작인지, 인디 게임인지" 알기 어렵다.

전문가 지식으로 피처 만들기

용량 → AAA 여부

45GB 대작 vs 500MB 인디 게임. 숫자 그대로 두지 말고 의미 있는 피처로 변환한다.

df['is_AAA'] = (df['용량'] >= 30000).astype(int)
출시일 → 시즌 피처

게임은 연말(11~12월) 출시 시 판매량이 높다. 날짜 숫자에서 의미 있는 정보를 뽑아낸다.

df['is_holiday_season'] = df['출시월'].isin([11, 12]).astype(int)
df['game_age_days'] = (오늘날짜 - df['출시일']).days
장르코드 → 원-핫 인코딩

장르코드 3보다 "RPG인지 FPS인지"가 훨씬 강력한 정보다.

주기적 특성 — 스팀 정기 세일

스팀 정기 세일은 1년에 여러 번 반복된다. sin/cos 변환으로 "세일 직전 출시 게임의 판매 급등" 패턴을 잡을 수 있다.

전문가 지식의 힘

"용량=45000"보다 "AAA 대작, 연말 출시, RPG 장르"라는 정보가 모델에게 훨씬 강력하다. 데이터를 많이 모으는 것보다 올바른 피처를 만드는 것이 더 중요할 때도 있다.

요약 및 정리

① 범주형 변수 — 원-핫 인코딩

순서 없는 범주형은 OneHotEncoder, 순서 있는 범주형은 OrdinalEncoder. 숫자 그대로 쓰면 모델이 잘못된 순서 관계를 학습한다.

② 구간 분할 — 선형 모델에만 효과

연속값을 구간으로 나누면 선형 모델이 비선형 패턴을 학습할 수 있다. 트리 모델에는 불필요하다. KBinsDiscretizer 사용.

③ ColumnTransformer — 실전의 핵심

수치형/범주형 컬럼에 각각 다른 전처리를 적용. make_column_transformer로 간결하게 작성. Pipeline과 함께 쓰면 데이터 누수 없이 안전한 전처리 가능.

④ 상호작용/다항식 — 피처 조합으로 표현력 향상

PolynomialFeatures로 제곱, 교차항 생성. 피처 수가 폭발할 수 있으니 특성 선택과 함께 사용 권장.

⑤ 특성 선택 3가지

일변량 통계(빠름, 독립 평가) → 모델 기반(중간, 관계 고려) → RFE(느림, 가장 정밀). 상황에 따라 선택.
