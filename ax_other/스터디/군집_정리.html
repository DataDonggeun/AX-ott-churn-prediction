군집이란?

군집은 데이터셋을 클러스터라는 그룹으로 나누는 작업이다. 클러스터 안의 데이터 포인트끼리는 매우 비슷하고, 다른 클러스터의 데이터 포인트와는 구분되도록 나누는 것이 목표다.

군집은 각 데이터 포인트가 레이블을 가진다는 면에서 분류와 조금 비슷해 보인다. 그러나 정답을 모르고 있으며 레이블 자체에 어떤 의미가 있지는 않다. 예를 들어 얼굴 이미지를 군집화하면 알고리즘이 "클러스터 3"이라고 묶어줬을 때 그 숫자가 누구인지는 모른다. 중요한 건 같은 그룹 안의 얼굴들이 서로 비슷하다는 사실이다.

scikit-learn

Python 기반의 오픈소스 머신러닝 라이브러리로, 분류·회귀·군집화·차원 축소 등 대부분의 머신러닝 알고리즘을 포함한다. 이 챕터에서 다루는 모든 군집 알고리즘은 scikit-learn으로 구현한다.

지도 학습 (분류)
  • 레이블이 있음 (y = 0 또는 1)
  • 모델이 정답을 학습
  • 클래스 이름이 의미 있음
비지도 학습 (군집)
  • 레이블이 없음
  • 비슷한 것끼리 자동 분류
  • 클러스터 번호는 의미 없음

k-평균 알고리즘

k-평균은 가장 간단하고 널리 쓰이는 군집 알고리즘이다. 클러스터 중심(센트로이드)을 찾고, 각 데이터 포인트를 가장 가까운 클러스터 중심에 할당한다.

k-Means 동작 순서
1단계: k개의 클러스터 중심을 랜덤하게 초기화
2단계: 각 데이터 포인트를 가장 가까운 클러스터 중심에 할당
3단계: 할당된 데이터 포인트의 평균으로 클러스터 중심을 다시 지정
4단계: 포인트에 변화가 없을 때까지 2–3단계를 반복하고 종료
k-평균 수렴 과정 — 빨강/파랑이 두 클러스터, 큰 원이 클러스터 중심

sklearn 코드

from sklearn.datasets import make_blobs
from sklearn.cluster  import KMeans

X, y = make_blobs(random_state=1)

kmeans = KMeans(n_clusters=3)
kmeans.fit(X)

print(kmeans.labels_)              # 각 샘플의 클러스터 번호
print(kmeans.cluster_centers_)    # 클러스터 중심 좌표
k-means++ 초기화

기본값인 init='k-means++'는 클러스터 중심을 서로 멀리 떨어진 위치에서 초기화하여 랜덤보다 훨씬 안정적인 결과를 낸다. n_init=10은 10번 다른 초기값으로 실행한 후 가장 좋은 결과를 선택한다.

k-평균의 한계

k-평균은 비교적 이해하기 쉽고 구현도 쉬울 뿐만 아니라 비교적 빠르기 때문에 인기가 있다. 하지만 다음과 같은 단점이 있다.

무작위 초기화

알고리즘 출력이 난수 초깃값에 따라 달라진다. k-means++와 n_init으로 완화 가능.

클러스터 모양 가정

각 클러스터를 정의하는 것이 중심 하나뿐이므로 클러스터는 둥근 형태로만 나타낸다. 복잡한 형태를 구분하지 못한다.

k를 미리 지정해야 함

찾으려는 클러스터 개수를 반드시 지정해야 한다. 데이터셋의 클러스터 개수를 정확히 알고 있더라도 항상 구분해낼 수 있는 것은 아니다.

둥근 형태를 가정하기 때문에 복잡한 모양의 클러스터에서 실패한다

병합 군집 (Agglomerative Clustering)

병합 군집은 군집 알고리즘의 모음을 말한다. 시작할 때 각 포인트를 하나의 클러스터로 지정하고, 어떤 종료 조건을 만족할 때까지 가장 비슷한 클러스터를 합쳐나간다. scikit-learn에서 사용하는 종료 조건은 클러스터 개수로, 지정된 개수의 클러스터가 남을 때까지 비슷한 클러스터를 합친다.

병합 군집 동작 순서 (Bottom-Up)
시작: 모든 데이터 포인트 = 각자 하나의 클러스터 (n개)
반복: 현재 클러스터 중 가장 가까운 두 클러스터를 찾아 합침
종료: 지정한 k개의 클러스터가 남으면 종료

연결(Linkage) 방법

두 클러스터 사이의 거리를 어떻게 정의하느냐에 따라 linkage가 나뉜다.

ward (기본값, 권장)

모든 클러스터 내의 분산을 가장 작게 증가시키는 두 클러스터를 합친다. 크기가 비교적 비슷한 클러스터가 만들어진다. 대부분의 경우 가장 좋은 결과를 낸다.

complete (최장 연결)

두 클러스터에서 가장 먼 두 포인트 사이의 거리가 가장 짧은 두 클러스터를 합친다. 비교적 균등한 크기의 클러스터를 만든다.

average (평균 연결)

두 클러스터에 속한 모든 포인트 쌍의 평균 거리가 가장 짧은 두 클러스터를 합친다. ward와 complete의 중간 성격이다.

single (최단 연결)

두 클러스터에서 가장 가까운 두 포인트 사이의 거리가 가장 짧은 두 클러스터를 합친다. 체인처럼 길게 늘어진 클러스터가 만들어지는 경향이 있어 일반적으로 비추천.

linkage거리 기준클러스터 모양권장
ward분산 증가량 최소화균등한 크기권장
complete두 클러스터의 최대 거리균등한 크기좋음
average두 클러스터의 평균 거리중간보통
single두 클러스터의 최소 거리체인형비추
from sklearn.cluster import AgglomerativeClustering

agg = AgglomerativeClustering(n_clusters=3)           # 기본: ward
agg = AgglomerativeClustering(n_clusters=3, linkage='complete')
labels = agg.fit_predict(X)
중요한 한계

k-평균과 달리 predict() 메서드가 없다. 새로운 데이터 포인트가 추가되면 전체를 다시 군집화해야 한다.

덴드로그램 (Dendrogram)

덴드로그램은 병합 군집의 전체 계층 구조를 시각화한 트리 그래프다. 어떤 시점에서 어떤 클러스터들이 합쳐졌는지, 그 거리(높이)는 얼마인지를 보여준다.

가로 절단선 위치가 클러스터 수를 결정한다. 위에서 자를수록 k가 작아진다.
1
세로축 = 병합 거리위로 갈수록 멀리 있는 것을 합친 것이다.
2
가로선을 그으면그 선을 지나는 세로선의 수 = 클러스터 수 k
3
가장 긴 세로 구간두 수평선 사이 간격이 가장 넓은 곳에서 절단하면 가장 자연스러운 k를 얻는다.
from scipy.cluster.hierarchy import dendrogram, ward

linkage_array = ward(X)
dendrogram(linkage_array)

DBSCAN

Density-Based Spatial Clustering of Applications with Noise

DBSCAN의 주요 장점은 클러스터의 개수를 미리 지정할 필요가 없다는 점이다. 복잡한 형상도 찾을 수 있으며, 어떤 클래스에도 속하지 않는 포인트를 구분할 수 있다. 병합 군집이나 k-평균보다는 다소 느리지만 비교적 큰 데이터셋에도 적용 가능하다.

특성 공간에서 가까이 있는 데이터가 많아 붐비는 지역의 포인트를 찾는다. 이런 지역을 밀집 지역이라고 한다.

두 가지 핵심 매개변수

eps

어떤 포인트를 이웃으로 볼지 결정하는 반경 거리. eps 거리 안에 데이터가 min_samples 개수만큼 들어 있어야 핵심 포인트가 된다.

  • eps를 매우 작게 → 모든 포인트가 잡음 포인트
  • eps를 매우 크게 → 단 하나의 클러스터
min_samples

eps 반경 안에 최소 몇 개의 포인트가 있어야 핵심 포인트가 되는지 결정한다.

  • min_samples를 키우면 핵심 포인트 수가 줄고 잡음 포인트가 늘어남
  • 덜 조밀한 지역 포인트가 잡음이 될지 클러스터가 될지를 결정

세 가지 포인트 유형

핵심 포인트

eps 반경 안에 min_samples 이상의 이웃이 있는 점. 클러스터의 중심부.

경계 포인트

핵심 포인트의 이웃이지만 스스로는 핵심 포인트가 아닌 점. 클러스터의 가장자리.

잡음 포인트

어느 핵심 포인트의 이웃도 아닌 점. 레이블 = -1

from sklearn.cluster      import DBSCAN
from sklearn.preprocessing import StandardScaler

# 거리 기반이므로 스케일 조정 먼저
X_scaled = StandardScaler().fit_transform(X)

dbscan = DBSCAN(eps=0.5, min_samples=5)
labels = dbscan.fit_predict(X_scaled)

print(set(labels))   # -1 포함 가능
eps 값을 쉽게 찾으려면

StandardScaler나 MinMaxScaler로 모든 특성의 스케일을 비슷한 범위로 조정해주는 것이 좋다. eps는 데이터 스케일에 크게 의존하기 때문이다.

레이블이 -1만 나온다면?

모든 데이터가 잡음 포인트로 분류된 것이다. eps 값을 크게 하여 포인트의 이웃을 늘리거나, min_samples 값을 낮추어 클러스터에 모을 포인트 수를 줄이면 된다.

k-평균과 병합 군집의 크기 조절 방식

k-평균과 병합 군집은 원하는 클러스터 개수를 직접 지정할 수 있다. DBSCAN은 eps 매개변수를 사용하여 클러스터 크기를 간접적으로 조절한다. eps를 증가시키면 하나의 클러스터에 더 많은 포인트가 포함되어 클러스터가 커지지만, 여러 클러스터를 하나로 합치게 될 수 있다.

어떤 상황에 어떤 알고리즘?
if 대용량 데이터이고 원형 클러스터가 예상된다:
→ k-Means (빠르고 단순, predict 가능)
elif 계층 관계가 궁금하거나 k를 모른다:
→ AgglomerativeClustering + 덴드로그램으로 k 탐색
elif 클러스터 형태가 복잡하거나 이상치가 있다:
→ DBSCAN (단, StandardScaler 전처리 필수)

군집 평가 지표

흔히 하는 실수

군집 모델을 평가할 때 accuracy_score를 사용하는 것은 잘못됐다. 군집 레이블은 번호가 임의로 배정되기 때문에 정확도 계산 자체가 의미없다. 반드시 군집 전용 지표를 사용해야 한다.

정답 레이블이 있을 때 — 외부 평가

ARI (Adjusted Rand Index)

두 군집 결과가 얼마나 같은 쌍을 묶었는지를 본다. 모든 점 쌍을 확인하며:

  • 정답에도 같은 군집, 예측에도 같은 군집 → 일치
  • 정답에서도 다른 군집, 예측에서도 다른 군집 → 일치
  • 그 외 → 불일치

범위: -1 ~ 1. 우연보다 못하면 음수가 된다.

NMI (Normalized Mutual Information)

정답 레이블을 알면 군집 예측이 얼마나 쉬워지는가를 정보 이론으로 측정한다. 정답과 예측 사이의 상호 정보량을 계산하고, 각각의 엔트로피로 나눠서 0~1로 정규화한다. 1일수록 좋다.

엔트로피: 불확실성의 양. 결과를 예측하기 어려울수록 엔트로피가 높다.

ARI/NMI의 한계

군집 알고리즘을 적용할 때 보통 그 결과와 비교할 타깃이 없다. 정확한 클러스터를 알고 있다면 그 정보로 지도 학습 모델을 만들면 된다. 따라서 ARI와 NMI는 애플리케이션 성능 평가보다는 알고리즘을 개발할 때 도움이 된다.

정답 레이블이 없을 때 — 실루엣 점수

정답 레이블이 없을 때의 유일한 평가 수단이다. 클러스터의 밀집 정도를 계산하는 것으로 높을수록 좋으며 최대 점수는 1이다.

s = (b − a) / max(a, b)

a = 같은 클러스터 내 다른 포인트들과의 평균 거리 (작을수록 좋음)
b = 가장 가까운 다른 클러스터 포인트들과의 평균 거리 (클수록 좋음)

실루엣 점수의 함정

밀집된 클러스터를 선호하지만 클러스터 모양이 복잡할 때는 밀집도를 활용한 평가가 잘 맞지 않는다. 예를 들어 two_moons 데이터에서 DBSCAN이 올바르게 분류해도 k-평균보다 실루엣 점수가 낮게 나올 수 있다. 점수가 더 높다고 반드시 더 좋은 군집이 아니다.

from sklearn.metrics import adjusted_rand_score, silhouette_score

# 정답이 있을 때
adjusted_rand_score(y_true, labels_pred)

# 정답이 없을 때
silhouette_score(X, labels)
지표범위정답 필요?좋은 값
ARI-1 ~ 1필요1에 가까울수록
NMI0 ~ 1필요1에 가까울수록
실루엣-1 ~ 1불필요1에 가까울수록 (단, 맹신 금지)

얼굴 이미지 예제 — 세 알고리즘 비교

LFW(Labeled Faces in the Wild) 데이터셋을 사용해 얼굴 이미지를 군집화하는 예제다. 레이블 없이 비슷한 얼굴끼리 묶는 것이 목표다.

from sklearn.datasets    import fetch_lfw_people
from sklearn.decomposition import PCA
from sklearn.cluster    import KMeans, DBSCAN, AgglomerativeClustering

lfw = fetch_lfw_people(min_faces_per_person=20, resize=0.7)
X   = lfw.data   # (n, 5828) — 87x67 픽셀

# PCA로 차원 축소 (whiten=True: 각 컴포넌트 분산 통일)
pca   = PCA(n_components=100, whiten=True, random_state=0)
X_pca = pca.fit_transform(X)

알고리즘별 결과 차이

k-평균

클러스터 중심은 그 클러스터에 속한 얼굴 이미지들의 픽셀 평균값이다. 여러 얼굴이 겹쳐서 평균되므로 이미지가 흐릿하게 보인다.

DBSCAN

평균을 계산하지 않고 실제 데이터 포인트 자체를 클러스터로 묶기 때문에 실제 이미지가 그대로 나와 뚜렷하게 보인다. 잡음 포인트(레이블 -1)로는 모자를 쓰거나, 각도가 이상하거나, 너무 가깝거나 멀리서 찍힌 경우가 분류된다. 이런 분석을 이상치 검출이라고 한다.

더 많은 클러스터를 찾으려면 eps를 0.5~15 사이로 줄여서 조정한다.

병합 군집

클러스터 중심 개념이 없기 때문에 각 클러스터에서 중심에 가장 가까운 실제 이미지를 대표로 보여준다. 덴드로그램으로 병합 과정을 기록하고 원하는 k에서 잘라 클러스터를 만든다. 얼굴 데이터처럼 자연스러운 경계가 없는 데이터에서는 어디서 잘라야 할지 명확하지 않다.

세 알고리즘 요약 비교

k-평균: 클러스터 중심으로 클러스터를 구분, 각 포인트를 중심으로 대표 가능 → 분해 방법으로도 볼 수 있음
DBSCAN: 잡음 포인트를 인식, 클러스터 수 자동 결정, 복잡한 형태 인식 가능. 크기가 다른 클러스터를 만들어내는데 장점이기도 하고 단점이 되기도 함
병합 군집: 전체 데이터의 분할 계층도를 만들어주며 덴드로그램으로 쉽게 확인 가능

책 예제 이미지

k-평균 — 클러스터 중심(흐릿한 평균 얼굴) + 랜덤 샘플

DBSCAN — 잡음 포인트(이상치) 얼굴

병합 군집 — 클러스터별 대표 이미지 (k=40)
